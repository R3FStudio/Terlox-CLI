# Terlox 1.0.3

Terlox 1.0.3 focuses on the things you notice during a long terminal session:
responsive resizing, predictable clipboard shortcuts, and keeping output from
growing without a memory limit. It also adds useful commands that work straight
out of the box and makes release packaging more resilient.

## A steadier terminal for long sessions

Scrollback now has a **32 MiB cell-storage budget per session**, in addition to
the configured line limit. Terlox discards the oldest retained lines when either
limit is reached. A command that prints wide or very large logs can no longer
grow scrollback merely by making each retained line larger. Save important logs
to a file if you need a permanent record; evicted history cannot be recovered.

Incoming process output also has a bounded **1 MiB queue per session**. When a
program prints faster than the display can consume it, Terlox applies backpressure
through the native pipe and processes output in smaller batches. This preserves
the output and escape sequences while letting the UI handle input between batches.
These are limits on those buffers, rather than a cap on the entire application's
RAM: visible screens, graphics, fonts, Qt and running programs have their own costs.

## Resize and zoom without rebuilding everything

Window resizing now coalesces terminal-grid changes to roughly one update per
display frame and skips reflow when the row and column counts are unchanged.
The renderer keeps its glyph textures when only the window's dimensions change,
instead of throwing them away and rasterizing the same letters again. Text zoom
also avoids recreating native background effects. On Windows, ConPTY resizing
runs off the UI thread so a slow console-host resize does not stop the window
from processing input and output.

## Commands ready to use

**`terlox --version`** now prints the version plus a compact system and build
report without opening a GUI. It includes OS/kernel, architecture, logical CPU
threads, installed memory, root-disk space, Qt versions and the terminal's output
and history limits. The live renderer and session details remain available in F1.

Inside **`terloxsh`**, type **`fastfetch`**, **`fetch`** or **`sysinfo`** for the
built-in Terlox system report, or **`version`** for the same version and stats.
No additional download is needed. This is Terlox's own fetch-style implementation;
it does not bundle upstream Fastfetch or implement its configuration and options.

**`terlox clear`** clears visible text and retained scrollback in the current
terminal. It also works as an intercepted command at Terlox's interactive prompt,
alongside **`/terlox clear`** and the new **Clear terminal** context-menu action.
The `terloxsh` **`clear`** builtin now clears scrollback as well. Clearing does not
terminate the shell or delete files, and other tabs keep their own history.

## Clipboard keys that fit your platform

- **macOS:** Command+A/C/V for select all, copy and paste; physical Control keys
  remain available to shell applications.
- **Windows:** Ctrl+A selects all; Ctrl+C copies a selection and interrupts the
  running command when there is no selection; Ctrl+V pastes.
- **Linux:** Ctrl+Shift+A/C/V for select all, copy and paste. Ctrl+A, Ctrl+C and
  Ctrl+V are passed to the shell. Ctrl+Insert and Shift+Insert also copy and paste.

Bracketed paste remains supported when requested by the running application.

## Native Unix shell setup

Fresh Linux and macOS configurations now prefer an installed native shell,
honoring `SHELL` when it matches a discovered profile. This lets normal startup
files load tools such as nvm and keeps shell functions in one persistent session.
Saved explicit defaults are preserved. The included Terlox shell now recognizes
the escaped `\.` spelling and gives a useful native-shell explanation for `source`
and `.` instead of reporting a missing executable.

## More reliable packages

The packaging-tool downloader retries temporary HTTP failures, including the
504 gateway timeout seen in Linux builds. Retries are bounded, use exponential
backoff, and retain checksum verification. Downloads are cached only after a
complete verified response; permanent HTTP errors and checksum mismatches fail
immediately. CI also caches the pinned packaging tools between runs.

## Downloads and upgrading

This release includes the extracted installer files from the native build
artifacts, rather than GitHub Actions ZIP wrappers:

- **Windows x64:** `Terlox-1.0.3-windows-x64-setup.exe`
- **Linux x64:** `terlox_1.0.3_amd64.deb` or `Terlox-1.0.3-x86_64.AppImage`
- **macOS Apple Silicon:** `Terlox-1.0.3-macos-arm64.pkg`
- **macOS Intel:** `Terlox-1.0.3-macos-x64.pkg`

Choose the installer for your OS and architecture. Existing settings are retained.
If an older installation has **Terlox shell** saved as its default and you want
Bash, run `/terlox default-shell "bash"` and open a new session.
